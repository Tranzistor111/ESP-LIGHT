## 📖 Описание

**ESP-LIGHT** — это компактное портативное световое устройство на базе микроконтроллера ESP8266 (Wemos D1 mini) с адресными светодиодами WS2812. Устройство работает от литий-полимерного аккумулятора, имеет три режима работы и простое управление с помощью тактовых кнопок. Отлично подходит как декоративная подсветка, переносной фонарик или основа для более сложных световых проектов.

## 🔌 Схема подключения

> Прикрепите изображение схемы (`schematic.png` или `wiring.png`) в корень репозитория.

```
        ┌─────────────────────────────────────────┐
        │              Wemos D1 mini              │
        │                                         │
   ┌────┤  D1 ──────► WS2812 DI (Data In)        │
   │    │  D5 ──────► Кнопка OK (Смена режима)   │
   │    │  D6 ──────► Кнопка + (Яркость ▲)       │
   │    │  D7 ──────► Кнопка - (Яркость ▼)       │
   │    │  5V ──────► VCC модулей WS2812          │
   │    │  GND ─────► GND общий                   │
   │    │                                         │
   │    └─────────────────────────────────────────┘
   │
   │    ┌─────────┐    ┌─────────┐    ┌─────────┐
   └───►│ WS2812  │───►│ WS2812  │───►│ WS2812  │───► ... (5 шт.)
        │  #1     │    │  #2     │    │  #3     │
        └─────────┘    └─────────┘    └─────────┘

   Питание:
   АКБ 3.7V ──► TP4056 (заряд) ──► VIN Wemos D1 mini
   Кнопка питания разрывает цепь между АКБ и TP4056/Wemos
```

**Основные соединения:**
- **WS2812**: `DI` → `D1` (GPIO5), `VCC` → `5V`, `GND` → `GND` (цепочка из 5 модулей)
- **Кнопка OK**: один контакт → `D5` (GPIO14), другой → `GND` (включить внутренний pull-up)
- **Кнопка +**: один контакт → `D6` (GPIO12), другой → `GND`
- **Кнопка -**: один контакт → `D7` (GPIO13), другой → `GND`
- **Питание**: АКБ → TP4056 → `VIN`/`5V` Wemos D1 mini

## 🎨 Режимы работы

| Режим | Описание |
|-------|----------|
| 🌈 **Радуга** | Плавная смена цветов по всей палитре (Rainbow cycle) |
| 🎛 **Ручной** | Статический цвет с возможностью выбора оттенка |
| ⚡ **Мигалка** | Стробоскопический эффект, мерцание белым светом |

---

## 🎮 Управление

| Кнопка | Действие |
|--------|----------|
| **OK** | Переключение между режимами (Радуга → Ручной → Мигалка → Радуга...) |
| **+** | Увеличение яркости светодиодов |
| **-** | Уменьшение яркости светодиодов |

> **Примечание:** Яркость изменяется с шагом ~10–15%. При достижении максимума/минимума дальнейшее нажатие игнорируется или циклически переключается (зависит от прошивки).

## 🚀 Гайд по прошивке

### 1. Установка Arduino IDE

Скачайте и установите [Arduino IDE](https://www.arduino.cc/en/software) (версия 1.8.x или 2.x).

### 2. Добавление ядра ESP8266

1. Откройте **Файл → Настройки** (или `Ctrl + ,`)
2. В поле **«Дополнительные ссылки для Менеджера плат»** добавьте:
   ```
   https://arduino.esp8266.com/stable/package_esp8266com_index.json
   ```
3. Нажмите **OK**

### 3. Установка платы ESP8266

1. Перейдите в **Инструменты → Плата → Менеджер плат...**
2. В поиске введите **"ESP8266"**
3. Найдите **"ESP8266 by ESP8266 Community"** и нажмите **Установить**
4. Дождитесь завершения установки

### 4. Выбор платы

1. **Инструменты → Плата → ESP8266 Boards** → выберите **"LOLIN(WEMOS) D1 mini"**
2. **Порт:** выберите COM-порт, к которому подключена плата
3. **Upload Speed:** 921600
4. **CPU Frequency:** 80 MHz

### 5. Установка библиотек

Установите через **Скетч → Подключить библиотеку → Управлять библиотеками...**:
- **FastLED** by Daniel Garcia *(или* **Adafruit NeoPixel** by Adafruit *)*

### 6. Загрузка прошивки

1. Подключите Wemos D1 mini к ПК через USB
2. Откройте файл прошивки (`ESP-LIGHT.ino`)
3. Нажмите **Скетч → Загрузить** (или `Ctrl + U`)
4. Дождитесь сообщения **"Загрузка завершена"**

> 💡 **Совет:** Если загрузка не начинается, попробуйте зажать кнопку **FLASH** (или **BOOT**) на плате перед и во время начала загрузки.

## ⚠️ Важно

- **Полярность АКБ:** соблюдайте полярность при подключении литий-полимерного аккумулятора к TP4056! Переполюсовка приведёт к выходу из строя модуля заряда.
- **Ток потребления:** 5 светодиодов WS2812 при полной яркости потребляют до ~300 мА. Убедитесь, что АКБ и плата Wemos способны выдать нужный ток.
- **Зарядка:** используйте TP4056 только с Li-Po/Li-Ion аккумуляторами 3.7V. Не заряжайте и не используйте повреждённые батареи.
