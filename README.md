# ESP-LIGHT 💡

Портативный RGB-светильник на базе ESP8266 с управлением через тактовые кнопки. Проект идеально подходит для создания компактного декоративного освещения, ночника или портативного фонарика с различными световыми эффектами, а также светильника для съёмки.

---

## 📋 Описание проекта

**ESP-LIGHT** — это компактное устройство на базе микроконтроллера ESP8266 (Wemos D1 Mini), управляющее 5 светодиодными модулями WS2812. Устройство работает от литий-полимерного аккумулятора через модуль заряда TP4056, что делает его полностью автономным и портативным.

Проект поддерживает три режима работы светодиодов, переключаемых кнопкой **OK**, а также регулировку яркости кнопками **+** и **-**.

---

## 🛠 Компоненты

| Компонент | Количество | Описание |
|-----------|------------|----------|
| **Wemos D1 Mini** | 1 шт. | Микроконтроллер на базе ESP8266 |
| **WS2812** | 5 шт. | Адресуемые RGB-светодиодные модули |
| **Тактовая кнопка** | 3 шт. | Кнопки управления: OK, +, - |
| **Кнопка включения питания** | 1 шт. | Слайдер-кнопка ON/OFF |
| **TP4056** | 1 шт. | Модуль заряда Li-Po/Li-Ion аккумулятора |
| **АКБ 3.7V / 100–500 mAh** | 1 шт. | Литий-полимерный аккумулятор |

## 🎮 Управление

| Кнопка | Действие |
|--------|----------|
| **OK** | Переключение режима работы |
| **+** | Увеличение яркости |
| **-** | Уменьшение яркости |

---

## 🌈 Режимы работы

| Режим | Описание |
|-------|----------|
| **🌈 Радуга** | Плавная смена цветов по всей линейке WS2812 (эффект Rainbow) |
| **🎨 Ручной** | Статический цвет с возможностью выбора оттенка |
| **⚡ Мигалка** | Стробоскопический эффект с заданной частотой |

## 💻 Прошивка

### 1. Установка Arduino IDE

Скачайте и установите [Arduino IDE](https://www.arduino.cc/en/software) (версия 1.8.x или 2.x).

### 2. Добавление ядра ESP8266

1. Откройте **Файл → Настройки** (или `Ctrl + ,`)
2. В поле **«Дополнительные ссылки для Менеджера плат»** добавьте:
   ```
   https://arduino.esp8266.com/stable/package_esp8266com_index.json
   ```
3. Нажмите **OK**
4. Перейдите в **Инструменты → Плата → Менеджер плат…**
5. В поиске введите **«ESP8266»**
6. Установите пакет **ESP8266 by ESP8266 Community**
7. После установки выберите плату: **Инструменты → Плата → ESP8266 Boards → LOLIN(WEMOS) D1 mini**

### 3. Установка библиотеки

Установите следующию библиотеку через **Скетч → Подключить библиотеку → Управлять библиотеками…**:

- **Adafruit NeoPixel** — для управления WS2812

### 4. Загрузка прошивки

1. Подключите Wemos D1 Mini к компьютеру через USB
2. Выберите COM-порт: **Инструменты → Порт**
3. Откройте файл прошивки `ESP-LIGHT.ino`
4. Нажмите **Загрузить** (или `Ctrl + U`)
5. Дождитесь сообщения **«Загрузка завершена»**

> ⚠️ **Важно:** Если загрузка не начинается, зажмите кнопку **FLASH** (или **BOOT**) на плате перед и во время начала загрузки.

## 🔋 Питание

Устройство питается от одноэлементного Li-Po/Li-Ion аккумулятора (3.7V) через модуль TP4056. Модуль обеспечивает:

- Защиту от переразряда
- Защиту от перезаряда
- Возможность зарядки через micro-USB / USB-C

> 🔌 Для зарядки подключите кабель к разъёму на модуле TP4056. Индикатор покажет статус заряда (красный — заряжается, синий/зелёный — заряжен).
